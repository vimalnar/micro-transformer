# Micro-Transformer

Micro-Transformer is a compact, deterministic baseline for training and evaluating
a small transformer from scratch. It separates the language contract, procedural
data, interactive gridworld, and neural model so each component can be inspected,
tested, or replaced independently.

This documentation describes the repository's interfaces, experiments, guides,
and preliminary results. It does not claim general reasoning, persistent memory,
online learning, or machine consciousness.
